# KUMA Personal Space

單頁互動式個人介紹網站，無外部 JavaScript 套件、無 API Key、無追蹤程式。

## 檢視

以瀏覽器開啟 `index.html` 即可預覽。正式部署後網址為 `https://<GitHub 使用者名稱>.github.io/<儲存庫名稱>/`。

## 發布至 GitHub Pages

1. 在 GitHub 建立一個 **Public** 儲存庫（建議：`kuma-personal-space`），不必先建立 README。
2. 上傳本資料夾中的 `index.html` 及 `assets/` 目錄；或使用 Git。
3. 進入 Repository → Settings → Pages，選擇 `Deploy from a branch`、分支 `main`、目錄 `/ (root)`，按 Save。
4. GitHub Pages 啟用與部署成功後即可使用網站網址。

## 個人照片

目前首頁刻意使用 `K.` 佔位。待使用者提供照片後再替換，避免擅自公開個人肖像。

## 注意

- 公開儲存庫意味著所有網站文字及照片均可被他人瀏覽、下載。
- AI 專案僅有概念介紹，未放入公司內部債權資料、建商資料或敏感數據。

目前首頁展示的圖片為暫用的示意 SVG；個人實際作品照片可於後續更新 `assets/` 後置換。
